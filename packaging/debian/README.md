# Debian packaging

This directory holds the control files used to build cursorpop's `.deb` package.

## How to build the package

From the repository root:

```bash
make deb
```

That compiles the binary, runs `make install` into a temporary staging directory,
applies the control files from this directory and produces a `.deb` ready to distribute:

```
cursorpop_0.3.0_amd64.deb
```

To install it locally after building:

```bash
sudo dpkg -i cursorpop_0.3.0_amd64.deb
```

If a dependency is missing:

```bash
sudo apt install -f
```

## Files in this directory

| File | Purpose |
|------|---------|
| `control` | Package metadata (name, version, dependencies, description). The `@VERSION@` and `@ARCH@` placeholders are replaced with `sed` at build time. |
| `postinst` | Runs after install. Refreshes the desktop application database and the icon cache. |
| `prerm` | Runs before removal. Stops the daemon if it is running. |
| `postrm` | Runs after removal. Refreshes the desktop application database and the icon cache. |

## System dependencies to build

```bash
sudo apt install build-essential dpkg-dev gettext \
                 libx11-dev libxfixes-dev libxi-dev libxext-dev \
                 python3-gi gir1.2-gtk-3.0 gir1.2-xapp-1.0
```

## Notes

- Staging happens in `/tmp/cursorpop-deb-staging` and is removed automatically when done.
- The package is built with `dpkg-deb --root-owner-group` to avoid permission warnings.
- `mimeinfo.cache` is removed from the staging dir before packaging (it is generated by
  `update-desktop-database` during install and must not ship in the package).
